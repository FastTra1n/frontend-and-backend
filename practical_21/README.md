# Практическое задание №21: Кэширование с использованием Redis

В данной практической работе рассмотрен процесс работы с Redis и применением Redis для кэширования.
Реализовано кэширование ответов сервера с помощью Redis. Кэш позволяет сохранять результаты часто выполняемых запросов на заданное время, снижая нагрузку на основное приложение и ускоряя ответ клиенту.
Cозданы универсальные middleware для чтения из кэша и функция для сохранения данных в Redis (saveToCache). Для маршрутов установлено разное время жизни кэша (1 минута для пользователей, 10 минут для товаров).
