# Практическое задание №22: Балансировка нагрузки в веб-приложениях

В данной практической работе рассмотрено понятие балансировки нагрузки, настройку Nginx и HAProxy в роли балансировщиков, а также базовые подходы к развертыванию сбалансированных систем с помощью Docker Compose.
Изучена концепция балансировки нагрузки как механизма распределения входящего трафика между несколькими серверами для повышения производительности, отказоустойчивости и возможности горизонтального масштабирования.
Настроен Nginx в роли балансировщика. В конфигурации определена группа upstream с двумя основными backend-серверами на разных портах. Запросы последовательно распределяются между основными серверами.
Альтернативно рассмотрен HAProxy: приведён пример конфигурации с фронтендом, бэкендом с алгоритмом roundrobin и опцией check для активной проверки доступности серверов.
