# Практическое задание №23: Контейнеризация приложений с Docker

В данной практической работе рассмотрено понятие контейнеризации, ключевые концепции Docker, создание образов с помощью 
Dockerfile и управление многоконтейнерными приложениями через Docker Compose.
1. Освоены основные понятия контейнеризации и Docker: образ (неизменяемый шаблон), контейнер (запущенный экземпляр), Dockerfile (инструкции для сборки образа), Docker Compose (описание многоконтейнерных приложений), сети, тома и переменные окружения.
2. Изучена структура Dockerfile на примере Node.js-сервиса: выбор базового образа, установка рабочей директории, копирование файлов, установка зависимостей, указание порта и команды запуска. Оптимизация сборки за счёт кэширования слоёв.
