# Практическое задание №27: Брокеры сообщений. RabbitMQ и Kafka

В данной практической работе рассмотрен паттерн Message Queue, принципы работы брокеров сообщений RabbitMQ и Kafka, архитектура Producer-Consumer, организация воркер-процессов, а также практики повышения надёжности: retry logic с экспоненциальной задержкой и Dead Letter Queue.
