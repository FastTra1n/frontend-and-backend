# Практические задания №17: Детализация Push

В данной практической работе рассмотрена возможность push‑уведомлений, добавив в приложение заметок функционал напоминаний. В рамках практической работы реализовано:
1. Добавления заметок с указанием даты и времени напоминания.
2. Планирования push‑уведомлений на стороне сервера.
3. Отображения кнопок в уведомлении для возможности отложить напоминание.
4. Обработки действия «Отложить на 5 минут» через Service Worker
