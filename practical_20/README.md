# Практические задания №20: Работа с NoSQL СУБД на примере MongoDB

В данной практической работе рассмотрен процесс работы с NoSQL системами управления базами данных на примере СУБД MongoDB.
1. Выполнена установка MongoDB. В конфигурационном файле mongod.conf включена аутентификация (authorization: enabled), создан административный пользователь для доступа к базе данных.
2. Создан новый проект с помощью npm init -y, установлены зависимости express и mongoose. В файле server.js реализовано подключение к MongoDB . Настроен middleware express.json() для обработки JSON-запросов.
3. С помощью mongoose.Schema описана схема сущности «Пользователь» с полями: first_name, last_name, age, created_at, updated_at (типы – String, Number, Date). Создана модель User. Разработаны REST-маршруты для работы с пользователями.
