# Практические задания №13-14: Service Worker. Web App Manifest

В данной практической работе рассмотрена технология Service Worker, позволяющая создавать офлайн‑приложения, кэшировать ресурсы и перехватывать сетевые запросы, а также рассмотре Web App Manifest - файл, который превращает обычное веб-приложение в прогрессивное веб-приложение (PWA), позволяя устанавливать его на устройство и настраивать внешний вид.
