# Практические задания №19: Работа с реляционными СУБД на примере PostgreSQL

В данной практической работе рассмотрен процесс работы с реляционными системами управления базами данных на примере СУБД PostgreSQL.
1. Выполнена локальная установка PostgreSQL. Настроена база данных для хранения информации о пользователях.
2. Создан новый проект с помощью npm init -y, установлены зависимости express, pg и sequelize. В файле server.js реализовано подключение к PostgreSQL. Выполнена проверка подключения через sequelize.authenticate().
3. С помощью SQL-запросов созданы таблицы users и tasks с отношением «один-ко-многим» (внешний ключ user_id). В Sequelize определены модели User (поля: id, first_name, last_name, age, created_at, updated_at) и Task с установлением связей. Разработаны REST-маршруты для управления пользователями.
