# Использованные технологии

### Клиент

- React 19 (функциональные компоненты, хуки)
- React Router DOM (маршрутизация)
- Axios (интерцепторы для токенов)

### Сервер

- Node.js + Express.js
- JWT (access / refresh токены)
- bcrypt (хэширование паролей)
- nanoid (генерация ID)

# Реализованные эндпоинты

| Маршрут            | Метод  | Доступ        | Описание                         |
| ------------------ | ------ | ------------- | -------------------------------- |
| /api/auth/register | POST   | Гость         | Регистрация пользователя         |
| /api/auth/login    | POST   | Гость         | Вход в систему                   |
| /api/auth/refresh  | POST   | Гость         | Обновление пары токенов          |
| /api/auth/me       | GET    | Пользователь  | Получение текущего пользователя  |
| /api/users         | GET    | Администратор | Получить список пользователей    |
| /api/users/:id     | GET    | Администратор | Получить пользователя по id      |
| /api/users/:id     | PATCH  | Администратор | Обновить информацию пользователя |
| /api/users/:id     | DELETE | Администратор | Заблокировать пользователя       |
| /api/products      | GET    | Пользователь  | Получить список товаров          |
| /api/products      | POST   | Продавец      | Добавить новый товар             |
| /api/products/:id  | GET    | Пользователь  | Получить товар по id             |
| /api/products/:id  | PATCH  | Продавец      | Обновить информацию товара       |
| /api/products/:id  | DELETE | Продавец      | Удалить товар                    |

# Ролевая модель

| Роль                  | Права                                                              |
| --------------------- | ------------------------------------------------------------------ |
| Пользователь (user)   | Просмотр товаров, просмотр своего профиля, изменение пароля        |
| Продавец (seller)     | Всё, что может user, плюс создание/редактирование/удаление товаров |
| Адмниистратор (admin) | Всё, что может seller, плюс управление пользователями              |

# Установка и запуск проекта

> [!NOTE]
> Для корректной работы проекта необходим установленный Node.js и пакетный менеджер npm.

## Клонирование репозитория

```bash
git clone https://github.com/FastTra1n/frontend-and-backend
cd frontend-and-backend
```

## Установка зависимостей для каждого практического задания

Каждая практическая является самостоятельным проектом. Перейдите в нужную папку и установите зависимости:

```bash
cd practical_11  # или practical_4-5, practical_7-8 и т.д.
npm install
```

## Запуск в режиме разработки

```bash
npm run dev
```

Фронтенд обычно запускается на порту `5173` (Vite), бэкенд на порту `3000`.
Для работы с API **необходимо**, чтобы **сервер был запущен**.

# Примечания

- Практические задания выполнены в рамках семестровой работы. Код каждого практического задания находится в соответствующей папке.

- Для работы с API в клиентской части используется глобальный интерцептор `axios`, который добавляет `access token` к каждому запросу и автоматически обновляет его при истечении.

- В практических работах №4–5 использовалась имитация данных (mock), в последующих работах добавлено реальное взаимодействие с сервером.
